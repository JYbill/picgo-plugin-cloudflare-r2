# Mock 与真实依赖边界

mock 用来隔离被测单元，不用来代替正在验证的行为。

## 适合 mock

- 单元测试中慢、不稳定、收费或与当前规则无关的协作者。
- 某个依赖调用本身就是调用方依赖的契约。
- 为了确定性固定时间、随机数或进程环境。

## 使用真实依赖

- 验证数据库查询、事务、约束或 ORM 协同时，使用隔离的真实数据库。
- 验证 HTTP API 兼容性时，通过真实 HTTP 入口或客户端边界发起请求。
- 验证文件、队列、缓存或框架序列化行为时，使用可清理的真实测试边界。

## 交互断言

只在交互本身是稳定契约时断言 `toHaveBeenCalledWith()` 等调用细节。如果 wrapper 没有新增校验、转换、权限、事务、缓存、审计或稳定业务语义，不要只 mock 内部函数并断言它被调用；这类测试通常应删除，或改为验证 wrapper 真正增加的规则。
